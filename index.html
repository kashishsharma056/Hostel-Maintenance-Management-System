About The Project

The problem we are solving

The Problem

Hostel students report issues manually in paper registers. Complaints get forgotten and nobody knows their status.

Our Solution

A web-based system where students submit complaints, get a ticket ID and track progress, while the admin manages everything from one dashboard.

Technologies

Built using HTML, CSS and Vanilla JavaScript. Data is saved in the browser using localStorage.
