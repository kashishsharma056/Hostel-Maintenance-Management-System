HOSTELFIX - VIDEO-MATCHED FRONTEND RECREATION

Files:
- index.html
- style.css
- script.js

HOW TO RUN:
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension (if needed).
3. Right-click index.html and choose Open with Live Server.

IMPORTANT:
This recreates the landing page shown in your uploaded videos.
Student Login and Admin Login are placeholders and show a toast message.
The Contact Us form is a front-end demo; it does not send data to a server.
The complaint registration/admin dashboard shown in the Features text is not
implemented in this landing-page version.
